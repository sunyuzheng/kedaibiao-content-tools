# 网站嘉宾维护入口

公开目录的维护入口是[Open Context资料架构](https://github.com/sunyuzheng/lizheng-open-context/blob/main/docs/conversation-architecture.md)，网站操作入口是[Guests maintenance](https://github.com/sunyuzheng/lizheng-personal-site/blob/main/docs/guests-maintenance.md)。

本项目负责媒体归档、字幕处理和事实核对的上游证据。将已核对的公开人物与节目关系更新到Open Context后，网站同步固定release并验证现行页、旧链接、精选节目、来源链接和结构化数据。
