# 网站嘉宾数据说明

公开嘉宾目录已归入[Open Context](https://github.com/sunyuzheng/lizheng-open-context)。`catalog/guests.json`保存人物、别名、节目及参与关系，`catalog/guest-articles.json`保存已发表伴读文章链接。网站按固定commit和release manifest生成部署快照。

本地频道库继续管理媒体、原字幕、校对副本和证据。`guests.json`、`guest_video_metadata.json`及全量YouTube采集表用于频道维护和历史兼容；新的公开事实经核对后进入Open Context。

日常更新：核对原节目与作者资料 → 更新Open Context目录 → 运行release validation → 网站同步固定版本 → typecheck、build与线上链接验收。问问立正通过Open Context的release自动更新语料和索引。

网站的具体数据合同和命令见[lizheng-personal-site/docs/guest-data.md](https://github.com/sunyuzheng/lizheng-personal-site/blob/main/docs/guest-data.md)。
