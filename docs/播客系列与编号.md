# 播客系列与编号

## 已确定的规则

2026-09-18，用户确定把公开播客分为两个独立编号的系列：

- **对话 001｜标题正文**：嘉宾访谈、反向采访、多人讨论、合作演示。
- **立正说 001｜标题正文**：立正本人的独立讲解、演讲、现场答疑与个人分享。

`podcast_series.json` 是分类和系列序号的唯一来源，以 YouTube video_id 识别节目。`guests.json` 只提供分类线索，可能有遗漏，也可能把活动主办方误记为嘉宾；不得直接当作完整分类结果。

标题只显示系列序号，至少三位数字。Transistor/RSS 的 `episode.number` 继续使用全局期号，两者不要求相等。已有上下集和剪辑片段各自算一条已发布节目，保留原有标题正文中的上下集标注。两个系列仍共用同一节目与 RSS。

首次回填按原始 YouTube 发布日期、video_id 排序，分别从 001 开始。分配后序号固定，不因删除、取消发布、补发旧内容或手动改标题而自动重排。以后新节目使用所属系列的下一个未用序号；历史补发也追加，不能挤占已分配号码。

已发布标题的正文以 **Transistor 当前标题** 为准。修改前缀不能用本地旧标题覆盖用户在后台手动修改的正文。所有发布执行器必须使用已审核计划中冻结的完整 `target_title`，不能执行时重新推算。

## 新节目同步

1. 阅读原视频标题、简介；需要时检查字幕，确定是嘉宾内容还是立正个人内容。不能因为标题不含“访谈”就默认归立正说。
2. 写入本地目录，再生成同步计划：

   ```bash
   .venv-podcast/bin/python tools/podcast/assign_series.py \
     --video-id VIDEO_ID --series dialogue --date YYYYMMDD \
     --basis '已检查简介/字幕：与某嘉宾对谈'
   .venv-podcast/bin/python tools/check/build_podcast_sync_plan.py
   ```

   `--series solo` 对应立正说。命令只修改本地文件，不发布。已存在的归属拒绝覆盖；修改历史归属须另做精确改名清单。

3. 未分类的候选必须阻断发布并报告 `series_assignment_missing_or_invalid`。定时任务不得凭默认值猜测分类；在本地录入明确归属后才能继续原有自动发布门禁。
4. `projected_feed.target_title` 被既有审批 scope 哈希覆盖。执行器创建和修复草稿时使用此冻结标题。质检独立校验系列前缀、目录序号和全局期号。
5. 分类、编号规则变更须更新本文件及目录，运行播客测试与只读重排检查，提交并推送相关源码。

## 历史标题迁移

使用 `tools/upload/migrate_podcast_series.py` 生成完整 HTML、CSV 和冻结计划。公开前展示每一期旧标题、新标题、分类依据、目的地和受众，获得这份清单的明确批准。

```bash
# 只读生成完整清单
.venv-podcast/bin/python tools/upload/migrate_podcast_series.py \
  --review-dir logs/podcast_sync/series-review

# 仅在清单获明确批准后执行；HASH 必须来自该次审核的 plan.json
.venv-podcast/bin/python tools/upload/migrate_podcast_series.py \
  --review-dir logs/podcast_sync/series-review \
  --plan logs/podcast_sync/series-review/plan.json \
  --apply --approval-hash HASH
```

迁移只 PATCH `title`，验证身份、所属节目、原标题及受保护字段；不会改音频、简介、全局编号、GUID 对应的节目身份、URL slug 或发布日期。开始前检查整批前置条件；每一期更新前再次读取，更新后回读。执行中断可按同一计划恢复，已正确更新的条目跳过。执行日志与回执位于审阅目录。

定时发布仍拒绝所有涉及历史标题/期号的动作。迁移未完成时，普通计划会显示需要处理的历史改名，不能自动带入新节目发布。不得用旧版 `upload_to_transistor_v2.py` 绕过此流程。

迁移后用同一目录核对公开 RSS 全部标题及身份、媒体、期号未变；只读 planner/reorder 应无历史改名。修改标题后客户端刷新会有延迟。
